# neostellar-downloads
Página oficial de descarga de Neostellar para Windows x64, Linux x86_64 y Android.

La página apunta siempre al release estable más reciente. Actualmente: **v2.1.46**.

La guía pública está disponible en [Documentación](docs.html) e incluye instalación,
actualizaciones, multijugador y creación segura de mods.
